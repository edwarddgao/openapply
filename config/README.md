# Config

`applicant-profile.json` contains applicant facts and commitments: contact details, resume path, work authorization, sponsorship, availability, preferences, clearances, screening facts, demographics preferences, education, and languages.

`application-policy.json` contains reusable application answer strategy: referral-source fallbacks, cover-letter behavior, and how to apply facts from the applicant profile to recurring form questions.

`resume/` contains local resume files. These are sensitive and ignored.
